## Executive Overview

This report completes Assignment 4 (48-Hour Chart Hackathon) for EPPS 6356 Data Visualization. We implement the core chart paradigms from Andrew Abela’s Chart Thought-Starter (Comparison: Among Items branch) using the Happy Planet Index (HPI) dataset. All figures share a unified styling system defined in R/theme.R, adhere to Edward Tufte’s data-ink maximization[cite: 4, 16], utilize color-blind safe palettes (Okabe & Ito 2008)[cite: 11], and encode comparisons along common spatial baselines (Cleveland & McGill 1984).

## Chart 1: Variable-Width Column Chart

### Implementation (Comparison: Two Variables per Item)

Chart 1 maps two continuous macro-demographic dimensions simultaneously using geom_rect(): continental population determines rectangle width (\(W_i = xmax_i - xmin_i\)), while population-weighted Happy Planet Index determines column height (\(ymax_i\))[cite: 4, 5]. Interior polygon text has been eliminated to maximize the data-ink ratio and prevent label clipping across narrower columns (e.g., Oceania)[cite: 4, 5].

theme_hackathon <- function(base_size = 11,
                            base_family = "sans",
                            axis_slant = FALSE,
                            legend_pos = "top") {
  
  th <- theme_minimal(base_size = base_size, base_family = base_family) %+replace%
    theme(
      plot.title = element_text(
        size = rel(1.30),
        face = "bold",
        color = "#111111",
        hjust = 0,
        margin = margin(b = 6)
      ),
      plot.subtitle = element_text(
        size = rel(0.95),
        color = "#444444",
        hjust = 0,
        margin = margin(b = 12)
      ),
      plot.caption = element_text(
        size = rel(0.75),
        color = "#666666",
        hjust = 0,
        margin = margin(t = 12)
      ),
      
      axis.title.x = element_text(
        size = rel(0.90),
        face = "bold",
        color = "#222222",
        margin = margin(t = 8)
      ),
      axis.title.y = element_text(
        size = rel(0.90),
        face = "bold",
        color = "#222222",
        margin = margin(r = 8)
      ),
      axis.text = element_text(
        size = rel(0.82),
        color = "#333333"
      ),
      axis.line = element_line(
        color = "#777777",
        linewidth = 0.45
      ),
      axis.ticks = element_line(
        color = "#777777",
        linewidth = 0.40
      ),
      
      panel.grid.major = element_line(
        color = "#ECECEC",
        linewidth = 0.35
      ),
      panel.grid.minor = element_blank(),
      panel.background = element_rect(
        fill = "#FFFFFF",
        color = NA
      ),
      plot.background = element_rect(
        fill = "#FFFFFF",
        color = NA
      ),
      
      legend.position = legend_pos,
      legend.title = element_text(
        size = rel(0.85),
        face = "bold",
        color = "#222222"
      ),
      legend.text = element_text(
        size = rel(0.80),
        color = "#333333"
      ),
      legend.key = element_blank(),
      legend.background = element_blank(),
      
      strip.background = element_rect(
        fill = "#F2F4F8",
        color = NA
      ),
      strip.text = element_text(
        size = rel(0.88),
        face = "bold",
        color = "#222222",
        margin = margin(t = 4, b = 4)
      ),
      
      plot.margin = margin(t = 16, r = 18, b = 14, l = 16),
      plot.title.position = "plot",
      plot.caption.position = "plot"
    )
  
  if (isTRUE(axis_slant)) {
    th <- th + theme(
      axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1)
    )
  }
  
  return(th)
}

Analytical Takeaway

  • Demographic Scale vs. Ecological Efficiency: While Asia represents over 60% of the sample’s population (\(\approx 3.9\) billion people), its aggregate HPI (44.6) is heavily constrained by industrial carbon throughput. In contrast, the Americas achieve the highest population-weighted efficiency (49.8), demonstrating that high human wellbeing can be sustained at lower ecological impact.

Analytical Takeaway

  • The Decoupling Paradox: Economies with high GDP per capita (e.g., Luxembourg at $116,300 and the United States at $63,500) exhibit disproportionate ecological footprints (12.80 and 7.80 gha/capita), pulling their overall HPI scores below 45[cite: 4, 10]. Middle-income economies like Costa Rica (HPI 62.1) deliver comparable life expectancy with less than one-third of the ecological throughput[cite: 4, 10].

Chart 3: Horizontal Bar Chart of Ranked Cohorts

Implementation (Comparison: One Variable, Many Items)

Chart 3 benchmarks the Top 20 and Bottom 20 nations. Factor levels are ordered by continuous HPI score using forcats::fct_reorder(), eliminating alphabetical friction[cite: 4, 11]. The visual encoding uses an accessible, non-green Okabe-Ito color scheme (Okabe-Ito Blue #0072B2 vs. Vermilion #D55E00)[cite: 11].

Render Chart 3: geom_col() + fct_reorder() Horizontal Ranked Bars 
df_chart3 <- df_chart3_raw %>%
  mutate(
    country_ordered = fct_reorder(country, hpi),
    group = factor(group, levels = c("Top 20", "Bottom 20"))
  )

p3 <- ggplot(df_chart3, aes(x = hpi, y = country_ordered, fill = group)) +
  geom_col(
    width = 0.72,
    show.legend = FALSE
  ) +
  geom_text(
    aes(label = sprintf("%.1f", hpi)),
    hjust = -0.20,
    size = 3.1,
    fontface = "bold",
    color = "#222222"
  ) +
  facet_wrap(
    ~ group,
    scales = "free_y",
    ncol = 2
  ) +
  scale_fill_manual(
    values = c(
      "Top 20"    = "#0072B2",  # Okabe-Ito Blue
      "Bottom 20" = "#D55E00"   # Okabe-Ito Vermilion
    )
  ) +
  scale_x_continuous(
    name = "Happy Planet Index Score (0–100 Scale)",
    limits = c(0, 74),
    breaks = seq(0, 70, by = 10),
    expand = expansion(mult = c(0, 0.02))
  ) +
  scale_y_discrete(name = "Country") +
  labs(
    title = "Latin American Nations Lead Sustainable Efficiency While Fossil Rentiers and Fragile States Lag",
    subtitle = "Comparing the 20 highest- and 20 lowest-ranked global economies on the 2024 Happy Planet Index.",
    caption = "Source: Happy Planet Index (2024 Edition) | EPPS 6356 Hackathon"
  ) +
  theme_hackathon(legend_pos = "none") +
  theme(
    axis.text.y = element_text(size = rel(0.78), color = "#222222"),
    panel.spacing = unit(1.5, "lines"),
    strip.text = element_text(size = rel(0.95), face = "bold")
  )

## Chart 3: Horizontal Bar Chart of Ranked Cohorts

### Implementation (Comparison: One Variable, Many Items)

Chart 3 benchmarks the Top 20 and Bottom 20 nations. Factor levels are ordered by continuous HPI score using `forcats::fct_reorder()`, eliminating alphabetical friction[cite: 4, 11]. The visual encoding uses an accessible, non-green Okabe-Ito color scheme (Okabe-Ito Blue `#0072B2` vs. Vermilion `#D55E00`)[cite: 11].

