Project Overview

For Assignment 4 in Dr. Karl Ho’s EPPS 6356 Data Visualization course, our objective was to operationalize Andrew Abela’s Chart Thought-Starter taxonomy using empirical data from the 2024 Happy Planet Index (HPI). The assignment required building a fully reproducible, self-contained repository in R, deploying the resulting figures to GitHub Pages, and demonstrating clear collaborative ownership.

As team coordinator, I designed the foundation for the team before any visualization code was drafted. In line with Dr. Ho’s recommendation to settle design foundations early, I initialized the remote GitHub repository. I then developed, debugged, and refined Charts 1, 2, and 3, and established the branch architecture to delegate Chart 4 to my teammates.

This report documents the architectural setup, mathematical boundaries, visual design theories, debugging challenges, and substantive findings that went into completing this sprint. All figures share a unified styling system, adhere to Edward Tufte’s data-ink maximization, utilize color-blind safe palettes (Okabe & Ito 2008), and encode comparisons along common spatial baselines (Cleveland & McGill 1984).

Chart 1: Variable-Width Column Chart

Implementation (Comparison: Two Variables per Item)

Chart 1 maps two continuous macro-demographic dimensions simultaneously using geom_rect(): continental population determines rectangle width (\(W_i = xmax_i - xmin_i\)), while population-weighted Happy Planet Index determines column height (\(ymax_i\)). Interior polygon text has been eliminated to maximize the data-ink ratio and prevent label clipping across narrower columns (e.g., Oceania).

theme_hackathon <- function(base_size = 11,
                            base_family = "sans",
                            axis_slant = FALSE,
                            legend_pos = "top") {
  
  th <- theme_minimal(base_size = base_size, base_family = base_family) %+replace%
    theme(
      plot.title = element_text(
        size = rel(1.30),
        face = "bold",
        color = "#111111",
        hjust = 0,
        margin = margin(b = 6)
      ),
      plot.subtitle = element_text(
        size = rel(0.95),
        color = "#444444",
        hjust = 0,
        margin = margin(b = 12)
      ),
      plot.caption = element_text(
        size = rel(0.75),
        color = "#666666",
        hjust = 0,
        margin = margin(t = 12)
      ),
      
      axis.title.x = element_text(
        size = rel(0.90),
        face = "bold",
        color = "#222222",
        margin = margin(t = 8)
      ),
      axis.title.y = element_text(
        size = rel(0.90),
        face = "bold",
        color = "#222222",
        margin = margin(r = 8)
      ),
      axis.text = element_text(
        size = rel(0.82),
        color = "#333333"
      ),
      axis.line = element_line(
        color = "#777777",
        linewidth = 0.45
      ),
      axis.ticks = element_line(
        color = "#777777",
        linewidth = 0.40
      ),
      
      panel.grid.major = element_line(
        color = "#ECECEC",
        linewidth = 0.35
      ),
      panel.grid.minor = element_blank(),
      panel.background = element_rect(
        fill = "#FFFFFF",
        color = NA
      ),
      plot.background = element_rect(
        fill = "#FFFFFF",
        color = NA
      ),
      
      legend.position = legend_pos,
      legend.title = element_text(
        size = rel(0.85),
        face = "bold",
        color = "#222222"
      ),
      legend.text = element_text(
        size = rel(0.80),
        color = "#333333"
      ),
      legend.key = element_blank(),
      legend.background = element_blank(),
      
      strip.background = element_rect(
        fill = "#F2F4F8",
        color = NA
      ),
      strip.text = element_text(
        size = rel(0.88),
        face = "bold",
        color = "#222222",
        margin = margin(t = 4, b = 4)
      ),
      
      plot.margin = margin(t = 16, r = 18, b = 14, l = 16),
      plot.title.position = "plot",
      plot.caption.position = "plot"
    )
  
  if (isTRUE(axis_slant)) {
    th <- th + theme(
      axis.text.x = element_text(angle = 45, hjust = 1, vjust = 1)
    )
  }
  
  return(th)
}

Analytical Takeaway

  • The Population Weighting Effect: Looking strictly at national averages, Latin American nations post the highest individual HPI scores globally. However, when weighting by population, Europe leads all continents with a score of 49.4 across roughly 750 million people. The Americas place second at 46.7; while countries like Costa Rica (62.1) and Colombia (60.2) demonstrate world-class efficiency, the region’s aggregate score is pulled down by the demographic mass and heavy ecological footprint of the United States (37.4 across 333 million people).
  • Demographic Mass vs. Sustainable Return: Asia spans the largest horizontal share of the chart—representing nearly 4 billion people in this sample—yet achieves an intermediate efficiency score of 44.9. Oceania maintains a solid 46.0, though its demographic footprint is a narrow sliver on the far right (roughly 32 million people). Africa records the lowest regional weighted score at 36.6 across roughly 880 million people, constrained primarily by systemic deficits in life expectancy and basic public health infrastructure rather than resource overconsumption.

Analytical Takeaway

  • The Income–Footprint Decoupling: The inline pressure bars visually expose that high national wealth does not translate into sustainable efficiency. High-income economies like Luxembourg ($116,300 GDP pc) and Qatar ($93,500 GDP pc) achieve high life expectancy (82.6 and 79.3 years), but generate massive ecological footprints (12.80 and 14.30 gha/capita). These resource demands stretch their pressure bars to the maximum and drag their overall HPI scores down to 33.5 and 22.6.
  • High Efficiency at Low Cost: Middle- and low-income economies achieve comparable health and happiness outcomes at a fraction of the ecological throughput. Costa Rica ($20,300 GDP pc) and Vanuatu ($3,150 GDP pc) deliver life expectancies of 80.3 and 70.5 years with subjective wellbeing at 7.0/10, all while keeping footprints under 2.7 gha/capita. Their efficiency bars fill nearly two-thirds of the cell, demonstrating that human development does not require exponential carbon consumption.
  • Two Routes to Low Scores: The bottom rows highlight two distinct failure mechanisms. In the United States (HPI 37.4) and Qatar (HPI 22.6), low efficiency stems from excessive consumption (footprints of 7.80 and 14.30 gha). In the Central African Republic (HPI 21.1), the low score is driven by acute humanitarian hardship—life expectancy drops to 53.9 years and wellbeing falls to 3.5, even though its footprint is minimal at 1.45 gha/capita.

Chart 3: Horizontal Bar Chart of Ranked Cohorts

Implementation (Comparison: One Variable, Many Items)

Chart 3 compares the Top 20 and Bottom 20 HPI countries on one continuous horizontal scale. Countries are ordered by HPI using forcats::fct_reorder(), which removes alphabetical ordering and makes the ranking directly visible. Bar length and position encode HPI on a common baseline, while a color-blind-safe green–vermilion palette distinguishes the two cohorts. A separator line marks the boundary between the Top 20 and Bottom 20.

Analytical Takeaway

  • Large spread across the ranking: The continuous ordering reveals a substantial gap between the highest- and lowest-ranked countries. Costa Rica has the highest HPI score at 62.1, while the Central African Republic has the lowest score at 21.1, producing a difference of 41.0 points. Displaying all 40 countries on one common scale makes this overall spread immediately visible and easier to compare than if the two cohorts were shown in separate panels.

  • Regional concentration among the highest-ranked countries: Many of the highest HPI scores are concentrated in Latin America and the Caribbean. Costa Rica, Colombia, Ecuador, Panama, Jamaica, Guatemala, Honduras, Nicaragua, Peru, Mexico, and the Dominican Republic all appear in the Top 20. However, the Top 20 is not regionally uniform, as countries such as Switzerland, Norway, Finland, Spain, Japan, Vietnam, and the Philippines also rank highly.

  • The Bottom 20 is geographically diverse: The lower end of the ranking includes countries from Africa, Europe, Asia, the Americas, and the Middle East. Examples include Senegal, Ghana, Kenya, Estonia, Bulgaria, Egypt, Uganda, the United States, Tanzania, Saudi Arabia, Ethiopia, Nigeria, Luxembourg, the United Arab Emirates, South Africa, Sierra Leone, Mongolia, Zimbabwe, Qatar, and the Central African Republic. This indicates that low HPI scores are not confined to a single region.

  • The visualization emphasizes comparison rather than explanation: Chart 3 shows how countries differ in HPI score, but it does not by itself explain why those differences occur. Variables such as life expectancy, wellbeing, ecological footprint, and GDP per capita are present in the dataset, but they are not encoded in this chart. Therefore, the chart should be interpreted as a ranked comparison of HPI outcomes rather than as evidence of causal relationships.

Chart 4: Column Chart of Continental Means

Implementation (Comparison: One Variable across a Few Items)

Chart 4 completes the Abela comparison branch at its coarsest grain: one variable (the Happy Planet Index) across a few items (the five continents). Continents are ordered by mean HPI with forcats::fct_reorder() rather than alphabetically, so the ranking is read from position along a common baseline (Cleveland & McGill 1984) instead of recovered by scanning labels. The mean here is unweighted, which distinguishes it from the population-weighted mean in Chart 1; the two figures are not interchangeable and the subtitle says so. Because a continental mean conceals how many countries it averages — four for Oceania against seventeen for Asia — the count is printed inside each column rather than relegated to a footnote.

Render Chart 4: geom_col() Continental Means with Embedded Counts 
df_chart4 <- hpi_clean %>%
  group_by(continent) %>%
  summarise(
    mean_hpi = mean(hpi, na.rm = TRUE),
    n        = dplyr::n(),
    .groups  = "drop"
  ) %>%
  mutate(continent_ordered = fct_reorder(continent, mean_hpi, .desc = TRUE))

p4 <- ggplot(df_chart4, aes(x = continent_ordered, y = mean_hpi, fill = continent)) +
  geom_col(
    width = 0.68,
    show.legend = FALSE

  geom_text(
    aes(label = sprintf("%.1f", mean_hpi)),
    vjust = -0.55,

Analytical Takeaway

  • The Americas lead on efficiency, not on income. At a mean of 53.5 across sixteen countries, the Americas sit roughly six points above Oceania (49.7) and nearly six above Europe (47.9), despite a lower average GDP per capita than Europe. This is the HPI’s central claim made visible at continental scale: the index rewards converting resources into long, satisfying lives, not accumulating resources.
  • Africa’s position is a footprint artefact as much as a wellbeing one. Africa’s mean of 36.3 is the lowest of the five, but the cohort spreads from 21.1 to 47.6 — a range wider than the gap between the top two continents. Reading the column as a statement about “Africa” rather than about its mean would be exactly the error the embedded counts are there to resist.
  • Oceania’s column is the least reliable and says so. Four countries stand behind a mean of 49.7, against seventeen behind Asia’s 43.3. Printing n inside the bar keeps that asymmetry in the reader’s eye at the moment of comparison; without it, five columns of identical construction imply five estimates of identical precision.
  • Sorting is the analysis. Ordering by mean rather than alphabetically turns the ranking into a single left-to-right read. Wickham (2010) names alphabetical ordering of categorical variables as a common and avoidable fault, after Wainer’s “Alabama first!”; here, sorting is what allows the title’s claim to be verified by looking.

Technical Troubleshooting & Debugging Log

During development, several technical issues required hands-on troubleshooting to keep the project moving:

  • Package Installation & System Permissions: Running install.packages("dplyr", "tidyr", ...) initially threw directory errors because missing c() wrappers caused R to misinterpret package names as local paths and download repositories. In addition, Windows compilation prompts for Rtools appeared. I resolved this by setting options(pkgType = "binary") to pull pre-compiled binaries, avoiding unnecessary local compiler builds.
  • Quarto Path Resolution: Early preview runs failed with cannot open the connection on source("R/theme.R") because the file was saved in an external folder. I wrote an inline script generator to save R/theme.R directly into the project root, satisfying the self-contained repository requirement.
  • YAML Parser Crashes: Quarto threw readBlockMapping2 errors due to a merged title/subtitle line and non-breaking space characters (\u00A0) in the YAML header. I rebuilt the front matter with standard two-space indentation and dedicated lines for every key.
  • Table Cell Clipping: The gt table’s right-aligned currency columns were getting clipped during headless rendering in Chrome. Setting fixed pixel widths on every column via cols_width() resolved the overflow.

For all these errors I asked Gemini- Flash Extended model. I gave my code and the warning error I got in the console to Gemini and asked why it happpened, and how I could fix it.

## Project Overview

For Assignment 4 in Dr. Karl Ho’s EPPS 6356 Data Visualization course, our objective was to operationalize Andrew Abela’s *Chart Thought-Starter* taxonomy using empirical data from the 2024 Happy Planet Index (HPI). The assignment required building a fully reproducible, self-contained repository in R, deploying the resulting figures to GitHub Pages, and demonstrating clear collaborative ownership.

As team coordinator, I designed the foundation for the team before any visualization code was drafted. In line with Dr. Ho’s recommendation to settle design foundations early, I initialized the remote GitHub repository. I then developed, debugged, and refined Charts 1, 2, and 3, and established the branch architecture to delegate Chart 4 to my teammates.

This report documents the architectural setup, mathematical boundaries, visual design theories, debugging challenges, and substantive findings that went into completing this sprint. All figures share a unified styling system, adhere to Edward Tufte's data-ink maximization, utilize color-blind safe palettes (Okabe & Ito 2008), and encode comparisons along common spatial baselines (Cleveland & McGill 1984).

## Chart 1: Variable-Width Column Chart

### Implementation (Comparison: Two Variables per Item)

Chart 1 maps two continuous macro-demographic dimensions simultaneously using `geom_rect()`: continental population determines rectangle width ($W_i = xmax_i - xmin_i$), while population-weighted Happy Planet Index determines column height ($ymax_i$). Interior polygon text has been eliminated to maximize the data-ink ratio and prevent label clipping across narrower columns (e.g., Oceania).

### Analytical Takeaway

- **The Income–Footprint Decoupling:** The inline pressure bars visually expose that high national wealth does not translate into sustainable efficiency. High-income economies like Luxembourg (\$116,300 GDP pc) and Qatar (\$93,500 GDP pc) achieve high life expectancy (82.6 and 79.3 years), but generate massive ecological footprints (12.80 and 14.30 gha/capita). These resource demands stretch their pressure bars to the maximum and drag their overall HPI scores down to **33.5** and **22.6**.
- **High Efficiency at Low Cost:** Middle- and low-income economies achieve comparable health and happiness outcomes at a fraction of the ecological throughput. Costa Rica (\$20,300 GDP pc) and Vanuatu (\$3,150 GDP pc) deliver life expectancies of 80.3 and 70.5 years with subjective wellbeing at 7.0/10, all while keeping footprints under 2.7 gha/capita. - **Two Routes to Low Scores:** The bottom rows highlight two distinct failure mechanisms. In the Central African Republic (HPI 21.1), the low score is driven by acute humanitarian hardship—life expectancy drops to 53.9 years and wellbeing falls to 3.5, even though its footprint is minimal at 1.45 gha/capita.

- **The visualization emphasizes comparison rather than explanation:** Chart 3 shows how countries differ in HPI score, but it does not by itself explain why those differences occur. ## Chart 4: Column Chart of Continental Means

### Implementation (Comparison: One Variable across a Few Items)

Chart 4 completes the Abela comparison branch at its coarsest grain: one variable (the Happy Planet Index) across a few items (the five continents). Continents are ordered by mean HPI with `forcats::fct_reorder()` rather than alphabetically, so the ranking is read from position along a common baseline (Cleveland & McGill 1984) instead of recovered by scanning labels. The mean here is **unweighted**, which distinguishes it from the population-weighted mean in Chart 1; the two figures are not interchangeable and the subtitle says so. Because a continental mean conceals how many countries it averages — four for Oceania against seventeen for Asia — the count is printed inside each column rather than relegated to a footnote.

```{r}
#| label: chart-4-continent-means
#| code-summary: "Render Chart 4: geom_col() Continental Means with Embedded Counts"
#| fig-width: 10.5
#| fig-height: 6.5

df_chart4 <- hpi_clean %>%
  group_by(continent) %>%
  summarise(
    mean_hpi = mean(hpi, na.rm = TRUE),
    n        = dplyr::n(),
    .groups  = "drop"
  ) %>%
  mutate(continent_ordered = fct_reorder(continent, mean_hpi, .desc = TRUE))

p4 <- ggplot(df_chart4, aes(x = continent_ordered, y = mean_hpi, fill = continent)) +
  geom_col(
    width = 0.68,
    show.legend = FALSE
  ) +
  geom_text(
    aes(label = sprintf("%.1f", mean_hpi)),
    vjust = -0.55,
    size = 3.6,
    fontface = "bold",
    color = "#222222"
  ) +
  geom_text(
    aes(y = 1.8, label = paste0("n = ", n)),
    size = 2.9,
    color = "#FFFFFF",
    fontface = "bold"
  ) +
  scale_fill_continent() +
  scale_x_discrete(name = "Continent") +
  scale_y_continuous(
    name   = "Mean Happy Planet Index Score (0-100 Scale)",
    limits = c(0, 62),
    breaks = seq(0, 60, by = 10),
    expand = expansion(mult = c(0, 0.02))
  ) +
  labs(
    title    = "The Americas Convert Resources into Wellbeing More Efficiently Than Any Other Continent",
    subtitle = "Unweighted mean Happy Planet Index of the countries in each continent; n gives the number of countries behind each column.",
    caption  = "Source: Happy Planet Index (2024 Edition) | EPPS 6356 Hackathon"
  ) +
  theme_hackathon(legend_pos = "none") +
  theme(
    # theme_hackathon() re-declares axis.title.y through %+replace% without an
    # angle, which prints the title flat and squeezes the panel; the same fix
    # is applied in Chart 1.
    axis.title.y = element_text(angle = 90, vjust = 2, margin = margin(r = 10))
  )

p4
```

### Analytical Takeaway

- **The Americas lead on efficiency, not on income.** At a mean of **53.5** across sixteen countries, the Americas sit roughly six points above Oceania (**49.7**) and nearly six above Europe (**47.9**), despite a lower average GDP per capita than Europe. This is the HPI's central claim made visible at continental scale: the index rewards converting resources into long, satisfying lives, not accumulating resources.
- **Africa's position is a footprint artefact as much as a wellbeing one.** Africa's mean of **36.3** is the lowest of the five, but the cohort spreads from 21.1 to 47.6 — a range wider than the gap between the top two continents. Reading the column as a statement about "Africa" rather than about its mean would be exactly the error the embedded counts are there to resist.
- **Oceania's column is the least reliable and says so.** Four countries stand behind a mean of **49.7**, against seventeen behind Asia's **43.3**. Printing `n` inside the bar keeps that asymmetry in the reader's eye at the moment of comparison; without it, five columns of identical construction imply five estimates of identical precision.
- **Sorting is the analysis.** Ordering by mean rather than alphabetically turns the ranking into a single left-to-right read. Wickham (2010) names alphabetical ordering of categorical variables as a common and avoidable fault, after Wainer's "Alabama first!"; here, sorting is what allows the title's claim to be verified by looking.

## Technical Troubleshooting & Debugging Log

During development, several technical issues required hands-on troubleshooting to keep the project moving:

- **Package Installation & System Permissions:** Running `install.packages("dplyr", "tidyr", ...)` initially threw directory errors because missing `c()` wrappers caused R to misinterpret package names as local paths and download repositories. In addition, Windows compilation prompts for Rtools appeared. I resolved this by setting `options(pkgType = "binary")` to pull pre-compiled binaries, avoiding unnecessary local compiler builds.
- **Quarto Path Resolution:** Early preview runs failed with `cannot open the connection` on `source("R/theme.R")` because the file was saved in an external folder. I wrote an inline script generator to save `R/theme.R` directly into the project root, satisfying the self-contained repository requirement.
- **YAML Parser Crashes:** Quarto threw `readBlockMapping2` errors due to a merged title/subtitle line and non-breaking space characters (`\u00A0`) in the YAML header. I rebuilt the front matter with standard two-space indentation and dedicated lines for every key.
- **Table Cell Clipping:** The gt table's right-aligned currency columns were getting clipped during headless rendering in Chrome. Setting fixed pixel widths on every column via `cols_width()` resolved the overflow.

For all these errors I asked Gemini- Flash Extended model. I gave my code and the warning error I got in the console to Gemini and asked why it happpened, and how I could fix it.
